Brandwright

Version control for brand design.

An agentic image editor that learns any brand's DNA, composes editable on-brand designs, critiques and improves its own work, and tracks every change — human or agent — as commits in one shared history.

prepared for the team · design owner: Kunal · build: Bhurva + Claude

In one paragraph. Brandwright is an AI copilot that lives inside an image editor and treats brand design the way engineers treat code. You point it at any brand's asset folder and it learns that brand into a living "genome": the exact colours, fonts, logos and shapes, the tone of voice, and the layout patterns it reads off real example ads. From there you create new images, edit existing ones, or riff on a reference, and it lays everything out on a normal editable canvas so you can move things, retype copy, and swap assets by hand. The twist: every change, yours or the AI's, is saved as a version, like commits in git. Asking for "four different images like this" gives you four branches to explore side by side. A second AI quietly checks each version against the brand rules and fixes anything off before you see it, keeping score so the work improves pass after pass. Because it remembers which versions you keep and which you discard, it gets better at your brand the more you use it. Good renders are saved forever, and you can even drop a finished design onto a different brand and watch it re-skin itself. It runs on DeepSeek for the thinking and GPT Image Flare for the imagery.

01 What makes it agentic

The brief asks for an agentic image editor, so agency is the behaviour, not a label. Brandwright takes a goal and drives it to a finished, on-brand result through a tool-using loop, correcting itself along the way.

02 Self-improvement: the loops that learn

Two nested feedback loops. An inner loop improves one design pass after pass; an outer loop learns from what you keep and makes the whole system better over time. We are honest about scope: no model weights are trained in a hackathon. The learning lives in a reward function, its weights, and induced brand rules — all of which we update and version.

inner loop

Reward-guided refinement

RLAIF-style: the critic scores a design, the generator edits the weakest dimensions and re-commits. Loop until R clears τ or stops improving. Each pass is a commit, so the reward curve is visible on the branch.

outer loop

Preference learning

Accept / edit / revert are implicit preferences (chosen ≿ rejected), DPO-style signal without the training cost. They reweight the reward and, on repeat, induce explicit genome rules.

transfer

Warm starts across brands

The reward is defined over abstract dimensions, so weights and rules learned on one brand seed priors for the next. It gets smarter overall, not just per-brand.

Reward dimensionHow it's measuredSignal
Palette fidelityΔE colour distance of used colours vs genome tokensdeterministic
Contrast / legibilityWCAG contrast ratio on every text layerdeterministic
Logo clear-space & safe zonesGeometry checks against the genome's spacing rulesdeterministic
Layout-archetype matchSimilarity to archetypes mined from the reference adshybrid
Hierarchy & visual balanceDeepSeek-Flash as judgemodel
Voice / copy fitDeepSeek-Flash as judge vs the genome's voicemodel

Reward mixes exact metrics with model judgement: R(spec) = Σ wᵢ · scoreᵢ. The deterministic terms keep it grounded; the learned weights wᵢ are what the outer loop tunes to the designer's taste.

03 Technical depth

The parts that make this a real system, not a wrapper around an image API.

IR

DesignSpec as an IR

The agent targets a structured intermediate representation; a renderer lowers it to pixels, like a compiler. Pixels are never the source of truth, so everything stays editable, diffable, and brand-constrained.

diff

Semantic diff over the IR

Layer-identity matching + field-level comparison yields "headline ✎, ink→blue, +charm" instead of a meaningless pixel delta.

store

Content-addressed assets

Every render is stored by hash and referenced from commits. A liked image is pinned forever; reproducibility is structural, not luck.

constraints

Valid-by-construction

Colours, fonts and logos can only come from the active genome. The agent searches a constrained space, so most brand violations are impossible, not just discouraged.

reward

Hybrid reward model

Deterministic metrics (ΔE, WCAG, geometry) + LLM-as-judge. Exact checks where possible, semantic judgement where needed.

infra

Rate-limit-aware orchestration

A queue with backoff, response caching, and pre-generated demo assets so the shared 429 limits never stall a live run.

SHOULD · phases 6–7

The win: critic loop + CI + self-learning, plus the edit and reference modes. Includes brand-voice copywriting, accessibility in CI, and the why-it's-on-brand rationale.

The flourish: re-skin onto another brand, multi-placement resize, campaign/batch mode, reference-from-upload, motion export, and a second live-ingested brand.
