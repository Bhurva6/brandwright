Brandwright Version control for brand design.

An AI copilot inside an image editor that learns any brand's DNA, composes editable on-brand designs, critiques its own work, and tracks every change — human or agent — as commits in one shared history.

The idea: git, mapped onto design

Because every design is structured data (a DesignSpec), the primitives of version control become native design operations. This is what makes the rest possible.

commit
A snapshot of the DesignSpec. Human edits, generator edits, and critic fixes all commit to one timeline.
branch
"Create 4 like this" = 4 branches. Each variation is a distinct creative direction, explored in parallel.
diff
A semantic diff, not a pixel diff. "headline ✎ · ink→blue · +charm" — you see what changed in design terms.
ci
The Critic Loop checks every commit against brand rules. Green passes; red auto-fixes before you see it.
rebase
Re-skin: replay a design onto a different brand genome. Near-free, because specs are brand-abstract.
revert
Jump to any version; blame shows who touched each layer. Non-destructive and fully reviewable.

System architecture

Four subsystems, one contract. A Brand Genome is ingested from any brand's assets; a human and a two-agent loop commit structured designs to a versioned repo; every commit is gated by brand CI derived from that genome; the canvas renders the working tree.

The version model

What the designer actually sees: one base, four directions, a self-healing history, and a re-skin that costs almost nothing.

Why it wins, by judging criterion

01

Output quality

Brand rules enforced on the data model + a critic that auto-fixes every commit. On-brand is provable, not hoped for.

02

System design

A versioned DAG of structured specs, written by three authors, gated by generated CI. One coherent, novel idea.

03

Speed & features

Branches, semantic diff, merge, revert, CI, re-skin, 3 modes — all fall out of the one spine.

04

UI / UX flow

A commit graph designers already understand, over a live editable canvas. Review and adjust, exactly as briefed.

05

Presentation

"Git for brand design" lands in one sentence, and the re-skin demos like a magic trick.
